Takseas is a game where you control a red ball to roll forward and backward. Your objective is to get the ball to the other end of the platform.

- Use W to jump
- Use A to roll towards the right
- Use D to roll towards the left

The game was made using godot, and the player logic(code) was written on GDscript
Uses a tile set obtained from online (credit: craftpix.net)
The game was based on the jumpstart tutorial (jumpstart.hackclub.com)
